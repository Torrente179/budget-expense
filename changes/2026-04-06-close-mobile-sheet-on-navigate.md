# Close Mobile Sheet on Navigation

## Summary
The mobile side panel (Sheet drawer) now closes automatically when the user taps a navigation link.

## Product Changes
- Tapping any nav item in the mobile drawer closes the panel before (or as) the page transition occurs.

## Data Model
N/A

## Validation
- Open the side panel on mobile.
- Tap any navigation item (e.g. Budgets, Investments).
- Verify the sheet closes and the correct page loads.
