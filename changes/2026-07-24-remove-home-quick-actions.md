# Remove Home quick-action shortcuts

## Summary

Removed the desktop Home shortcut row (Movements, Budget, Import CSV, Start review, and personalized goal CTAs).

## Product Changes

- Home no longer shows the pill/button shortcut grid under recent movements.
- Navigation remains via the main nav, FAB, and in-content links.

## Validation

- Open `/home` on desktop → no Movimientos / Presupuesto / Importar CSV / Iniciar revisión shortcut row.
- Mobile tab bar and FAB unchanged.
